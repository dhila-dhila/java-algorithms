# Java Algorithms

A small Java file implementing four classic algorithms, each with simple checks you can run.

## Contents
- `isPalindrome`: ignores case, spaces and punctuation
- `fibonacci`: iterative version (fast, no recursion)
- `binarySearch`: O(log n) search in a sorted array
- `bubbleSort`: returns a sorted copy without changing the original

## Requirements
- Java 11+

## Run
```bash
javac Algorithms.java
java Algorithms
```

Expected output ends with:
```
All checks passed.
```
